# One or Many

A swipe game for iPhone that trains English singular/plural agreement until it's automatic. Each card is a sentence with
one blank: swipe left for the singular form, right for the plural. Fast, correct answers score the most.

- Game design and rules: [docs/SPEC.md](docs/SPEC.md)
- Visual style ("Sticker arcade"): [docs/STYLE.md](docs/STYLE.md)
- Sentences: edit [tools/items_source.py](tools/items_source.py), then run `python3 tools/items_source.py` to regenerate
  `OneOrMany/Resources/items.json` (CI checks they match).

## Build and test

Needs Xcode 27; runs on iOS 18 and later (iOS 26 included).

```bash
xcodebuild test -project OneOrMany.xcodeproj -scheme OneOrMany -destination 'platform=iOS Simulator,name=iPhone 18 Pro'
```

The Xcode project is generated by `tools/genproj.py` (folders are synchronized, so new Swift files need no project
change). For signing, put your team in `Config/Local.xcconfig` (not committed):

```
DEVELOPMENT_TEAM = ABCDE12345
```

## TestFlight and releases

Same setup as [music-library](https://github.com/davidlago/music-library):

- `scripts/testflight.sh` archives, signs and uploads (`UPLOAD=0` exports an .ipa instead).
- CI (`.github/workflows/ci.yml`) builds and tests every push. A `vX.Y.Z` tag uploads that version to TestFlight; run
  the workflow by hand with `testflight=export` or `upload` to try it without a tag.
- CI signs with an Apple Distribution certificate and an App Store Connect API key, stored as repository secrets:
  `APPLE_DISTRIBUTION_CERTIFICATE_P12` / `_PASSWORD` (set with `scripts/set-signing-secret.sh "Apple Distribution"
  APPLE_DISTRIBUTION_CERTIFICATE`), `ASC_API_KEY` (the .p8 contents), `ASC_API_KEY_ID` and `ASC_API_ISSUER_ID`.
- `scripts/make-icon.swift` redraws the app icon.
